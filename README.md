# 🍷 MyWine - Your Personal Vineyard Tracker

[![GitHub Super-Linter](https://github.com/natansalda/mywine/workflows/Lint%20Code%20Base/badge.svg)](https://github.com/marketplace/actions/super-linter)
[![Get it on Google Play](https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png)](https://play.google.com/store/apps/details?id=pl.nataliana.mywine)

**MyWine** is a simple and intuitive Android application designed to help wine enthusiasts track their tasting experiences. Keep a detailed database of your favorite (and not-so-favorite) wines right in your pocket.

---

## ✨ Features

*   **Detailed Tracking:** Log wine name, vintage year, rating, color, and notes.
*   **Easy Search:** Quickly find that one specific bottle you loved.
*   **Multilingual Support:** Available in **English** and **Polish**.
*   **Modern UI:** Clean interface built with Material Design.

> 🧪 **Note:** The app is currently in active development.

## 🛠 Tech Stack

Built with modern Android development practices:

*   **Language:** Kotlin + Coroutines
*   **Architecture:** MVVM Pattern
*   **UI:** Navigation Component, Data Binding, RecyclerView
*   **Local Storage:** Room Database + LiveData
*   **Dependency Injection:** Koin
*   **Quality Assurance:** JUnit, Super-Linter

---

## 🚀 Getting Started

1. Clone the repository.
2. Open in Android Studio.
3. Build and run on your device or emulator.
